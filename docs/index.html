THE IDEA

Why use named tools?

A generic Graph POST lets an agent reach far beyond the task. Named tools make the available reads and campaign changes visible, reviewable, and narrow.

Five read tools plus prepare_campaign_change and commit_campaign_change.

03

Fresh-state check

Commit verifies the campaign still has the value that was reviewed.
